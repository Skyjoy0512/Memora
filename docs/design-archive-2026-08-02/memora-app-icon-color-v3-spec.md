# Memora App Icon — Color v3

The v3 geometry makes the capsules bolder and pulls the two center capsules closer together.

## Geometry

- Canvas: `1024 × 1024`
- Capsule width: `132`
- Capsule radius: `66`
- Outer gaps: `82` (`132 ÷ φ ≈ 81.58`)
- Center gap: `50` (`82 ÷ φ ≈ 50.68`)
- Short capsule height: `346` (`132 × φ² ≈ 345.60`)
- Long capsule height: `559` (`346 × φ ≈ 559.84`)
- Horizontal symbol bounds: `x 141–883`
- Vertical symbol bounds: `y 158–866`
- Artwork background: `#FBFBF9`

## Color

- Shared gradient origin: `#AAACAD`
- Blue endpoint: `#788FAE`
- Teal endpoint: `#6C9FA1`
- Sage endpoint: `#798973`
- Violet endpoint: `#897A99`

The SVG is the geometry and color master.
