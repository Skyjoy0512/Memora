# 録音中

ルート: `app/record.tsx`（状態: recording / paused）
種別: Full screen modal

## Purpose

**録音されていることを疑いの余地なく伝える。** そして止めたいときに確実に止められる。

Memora において音声の喪失は最も重大な失敗である。この画面の設計は「安心」と「確実性」を最優先する。

## User goal

会議に集中しながら、ときどき画面を見て「ちゃんと録れている」ことを確認したい。

## Information hierarchy

1. **録音中であることの表示**（最上位。疑いの余地なく）
2. **経過時間**
3. **音声レベル（波形）**
4. **操作**（一時停止 / 停止）
5. 補助情報（保存先、プロジェクト）

## Layout

```
┌─────────────────────────────────┐
│                          [閉じる]│
│                                 │
│                                 │
│          ● 録音中                │
│                                 │
│          12:34                  │
│                                 │
│     ▁▃▅▇▅▃▁▂▄▆▄▂▁▃▅▃▁          │
│                                 │
│                                 │
│   プロジェクト: 週次定例          │
│                                 │
│                                 │
│                                 │
│   ┌─────────┐   ┌─────────┐    │
│   │ 一時停止 │   │  停止   │    │
│   └─────────┘   └─────────┘    │
│                                 │
│         録音を破棄               │
│                                 │
│              safe area          │
└─────────────────────────────────┘
```

- **操作は下部に集約する。** 片手で届く位置（監査 H-4）
- 「閉じる」は録音を止めない。**画面を閉じるだけ**
- 「録音を破棄」は控えめな見た目にし、`Dialog` で確認する

## Interactions

| 操作 | 結果 |
|---|---|
| 一時停止 | 録音を一時停止。ボタンが「再開」に変わる |
| 再開 | 録音を再開 |
| 停止 | 録音を確定し保存。処理中へ移行し、画面を閉じる |
| 破棄 | **`Dialog` で確認**。「破棄する」で音声を削除、「録音を続ける」で戻る |
| 閉じる | 画面を閉じる。**録音は継続する** |
| Android 戻る | 画面を閉じる。**録音は継続する** |
| アプリをバックグラウンドへ | 録音を継続する |

**停止と破棄を視覚的に明確に分ける。** 停止は主要操作（`Button` の accent）、破棄は最下部の控えめな `LinkButton`。

## States

| 状態 | 表示 |
|---|---|
| **録音中** | `state-recording` のインジケータ。波形が動く。経過時間が進む |
| **一時停止** | インジケータが `state-idle`。波形は静止。経過時間は停止 |
| **保存中** | 停止直後。`Spinner` +「保存しています」。この間は操作を受け付けない |
| **エラー（録音失敗）** | `Alert` で理由を表示。**それまでの音声を保存する導線を必ず出す** |
| **ストレージ不足** | `Alert` +「空き容量が不足しています」。録音を停止して保存する導線 |
| **Reduce Motion** | 波形を静的な音量バーに置き換える。録音中は色 + テキストで表現 |

## Accessibility

- 録音状態を `accessibilityLiveRegion="assertive"` で通知する（状態変化は即座に伝える必要がある）
- 経過時間は VoiceOver で冗長に読み上げないよう、`accessibilityLabel` を「録音時間 12分34秒」の形にし、更新頻度を抑える
- 波形は装飾なので `accessibilityElementsHidden`
- **停止と破棄のラベルを明確に区別する**（誤操作防止）
- 破棄の `Dialog` は破壊的操作であることを読み上げで伝える
- ボタンは 44pt 以上、主要操作は 56pt を推奨
- **Reduce Motion 時は波形アニメーションを止める**

## Acceptance criteria

1. 録音中であることが**色・テキスト・動きの3つ**で表現される
2. 経過時間が等幅で表示され、数字が変わっても幅が動かない
3. 「閉じる」「Android 戻る」で**録音が停止しない**
4. 破棄には**必ず `Dialog` の確認がある**
5. 停止は1タップで完了し、音声が保存される
6. アプリをバックグラウンドにしても録音が継続する
7. 録音失敗時に**それまでの音声を保存する導線がある**
8. Reduce Motion 有効時、波形アニメーションが停止する
9. VoiceOver で録音状態の変化が通知される
10. 主要操作（一時停止・停止）が画面下部にあり、片手で届く
