# 文字起こし

配置: File Detail（`file/[id]`）内のTranscriptタブ

## Purpose

**会議の発言を読む。** Memora で最も長く読まれる画面。

## User goal

誰が何を言ったかを確認する。特定の箇所を探して、その部分の音声を聞き直す。

## Information hierarchy

セグメント単位で構成する。1セグメント = 1発言のまとまり。

```
話者名  00:12
発言の本文がここに入る。長い場合は折り返す。
```

- 話者が変わる箇所で明確に区切る
- 時刻は各セグメントに付ける（タップでその位置へシーク）
- **同一話者の連続する発言は話者名を繰り返さない**（冗長になるため）

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| セグメント | `Surface` + `PressableFeedback` | **`TranscriptSegment`** |
| 話者ラベル | `Chip` | **`SpeakerBadge`** |
| 時刻 | `Text`（`mono`） | — |
| 本文 | `Text`（`transcript` トークン） | — |
| 表示切替 | `Tabs` または `Chip` の選択 | — |

## Interactions

| 操作 | 結果 |
|---|---|
| セグメントをタップ | その位置から再生 |
| 長押し | コピー / 引用してタスク作成の `Menu` |
| スクロール | 自動追従を一時停止 |
| 再生 | 現在位置のセグメントが強調され、自動スクロールする |
| 表示切替 | 整形後 / 元の文字起こし を切り替え |

### 自動スクロールの規則

1. 再生中は現在位置のセグメントへ自動スクロールする
2. **ユーザーが手動スクロールしたら自動追従を止める**
3. 一定時間操作がなければ追従を再開する
4. 追従再開時は急に飛ばず、なめらかに移動する

## States

| 状態 | 表示 |
|---|---|
| **未処理** | 「文字起こしはまだありません」+ 開始 CTA |
| **処理中** | `ProcessingIndicator` + 進捗。完了部分から順次表示してもよい |
| **完了** | セグメント一覧 |
| **失敗** | `Alert` + 理由 + 再試行 |
| **話者判別なし** | 話者ラベルを出さず、時刻と本文のみ |
| **空**（無音だった） | 「音声から発言を検出できませんでした」 |

## Accessibility

- 各セグメントの読み上げ: 「{話者}、{時刻}、{本文}」を1つのラベルにまとめる
- 再生中のセグメントを `accessibilityState={{ selected: true }}` で示す
- **話者を色だけで区別しない。** 必ず話者名を表示する
- 長い本文でも VoiceOver が途中で切れないこと
- セグメントのタップ領域は 44pt 以上
- Dynamic Type で文字が大きくなっても折り返しが破綻しないこと
- 自動スクロールは Reduce Motion 時に瞬時移動にする

## Copy

| 要素 | テキスト |
|---|---|
| 表示切替 | 「整形後」「元の文字起こし」 |
| 未処理 | 「文字起こしはまだありません」 |
| 未処理 CTA | 「文字起こしを作る」 |
| 処理中 | 「文字起こしを作っています」 |
| 失敗 | 「文字起こしができませんでした」 |
| 再試行 | 「もう一度試す」 |
| 無音 | 「音声から発言を検出できませんでした」 |
| 話者未判別 | 話者ラベルを表示しない |

## Acceptance criteria

1. セグメントが話者・時刻・本文で構成される
2. **同一話者の連続発言で話者名が繰り返されない**
3. セグメントのタップでその位置から再生される
4. 再生中のセグメントが強調され、自動スクロールする
5. **手動スクロールで自動追従が止まり、一定時間後に再開する**
6. 話者が色だけでなく名前でも区別される
7. `transcript` タイポグラフィトークン（行間 1.69）が使われている
8. 整形後 / 元の文字起こしを切り替えられる
9. 処理失敗時に再試行できる
10. Dynamic Type 最大でも本文が読める
