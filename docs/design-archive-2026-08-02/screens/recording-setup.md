# 録音セットアップ

ルート: `app/record.tsx`（状態: setup）
種別: Full screen modal

## Purpose

**最小の手数で録音を始める。** 設定は任意であり、既定のまま「開始」できることが最優先。

## User goal

会議が始まった。すぐ録りたい。

## Information hierarchy

1. **開始ボタン**（最優先。他を見なくても押せる）
2. 保存先プロジェクト（既定: 前回と同じ）
3. 処理方式（既定: 設定に従う）
4. マイクの状態

## Layout

```
┌─────────────────────────────────┐
│                          [閉じる]│
│                                 │
│   録音の準備ができました          │
│                                 │
│   プロジェクト                   │
│   [週次定例        ▾]            │
│                                 │
│   文字起こし                     │
│   [この端末で処理  ▾]            │
│                                 │
│   🎤 マイクは使用できます         │
│                                 │
│                                 │
│      ┌───────────────┐          │
│      │   録音を開始   │          │
│      └───────────────┘          │
│              safe area          │
└─────────────────────────────────┘
```

**開始ボタンは下部中央。** 片手で押せる位置（監査 H-4）。

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| プロジェクト選択 | `Select` または `BottomSheet` + `RadioGroup` | — |
| 処理方式 | `Select` | — |
| マイク状態 | `Alert`（問題時）/ `Chip`（正常時） | — |
| 開始 | `Button`（accent, 大） | — |
| 閉じる | `CloseButton` | — |

## Interactions

| 操作 | 結果 |
|---|---|
| 録音を開始 | 録音中へ遷移 |
| プロジェクト選択 | `BottomSheet` で選択。新規作成も可 |
| 処理方式選択 | ローカル / クラウドを選択 |
| 閉じる | モーダルを閉じる |

## States

| 状態 | 表示 |
|---|---|
| **正常** | 開始ボタンが有効 |
| **権限未取得** | 「マイクを許可」CTA。開始ボタンは無効 |
| **権限拒否済み** | `Alert` +「設定アプリで許可してください」+ 設定を開く |
| **ストレージ不足** | `Alert` + 空き容量の案内。開始は可能だが警告 |
| **オフライン + クラウド処理選択** | 「オンラインになってから処理します」 |
| **上限到達** | `Alert` +「録音はできますが、文字起こしは上限に達しています」 |

**権限が無い場合でも、何をすれば良いかを必ず示す。**

## Accessibility

- 開始ボタンは 56pt 以上
- 権限拒否時の復帰手順が読み上げで理解できること
- `Select` の現在値が読み上げられること
- 開始ボタンに `accessibilityLabel="録音を開始"`

## Acceptance criteria

1. **既定設定のまま1タップで録音を開始できる**
2. 開始ボタンが画面下部にあり片手で届く
3. プロジェクトの既定値が前回の選択を引き継ぐ
4. 権限が無い場合、取得または設定アプリへの導線が示される
5. 権限拒否時に開始ボタンが無効化され、理由が表示される
6. オフラインでクラウド処理を選んだ場合、挙動が説明される
7. 開始ボタンが 56pt 以上
8. VoiceOver で各選択肢の現在値が分かる
