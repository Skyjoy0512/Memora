# 設定

ルート: `app/(tabs)/settings.tsx`
種別: Bottom Tab

## Purpose

**設定を変更する。** 現状 808 行あり、開発者向け項目と本番項目が混在している（監査 M-5）。

## User goal

必要な設定だけを素早く見つけて変える。

## Information hierarchy

グループ順:

1. **アカウント**（プラン、サインイン状態）
2. **文字起こしと要約**（処理方式、言語、AI プロバイダ）
3. **保存とデータ**（保存先、容量、書き出し）
4. **通知**
5. **表示**（テーマ、文字サイズ）
6. **アプリについて**（バージョン、規約）
7. **開発者向け**（開発ビルドのみ）

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| グループ | `Card` + `ListGroup` | — |
| 行 | `ListGroup.Item`（`.ItemPrefix/.ItemTitle/.ItemDescription/.ItemSuffix`） | — |
| トグル | `Switch` | — |
| 選択 | `Select` / `BottomSheet` + `RadioGroup` | — |
| 見出し | `Text` | `SectionHeader` |
| 破壊的操作 | `Button`（danger）+ `Dialog` | — |
| 状態バッジ | `Chip` | — |

**`ListGroup` を使う。** 設定では行区切りが意味的まとまりを持つ（`Section` とは判断が異なる）。

## Interactions

| 操作 | 結果 |
|---|---|
| 行をタップ | 詳細画面 / `BottomSheet` |
| トグル | 即座に反映・保存 |
| ログアウト | `Dialog` で確認 |
| アカウント削除 | `Dialog` で確認（文字入力による二重確認） |

## States

| 状態 | 表示 |
|---|---|
| **通常** | 設定一覧 |
| **保存中** | 該当行に控えめなインジケータ |
| **保存失敗** | `Alert` + 再試行 |
| **未サインイン** | アカウント欄にサインイン導線 |
| **オフライン** | 通信が必要な項目を無効化し理由を表示 |

## 開発者向けの扱い

監査 M-5 の解決。

- **本番ビルドでは表示しない**（`__DEV__` またはビルド構成で分岐）
- 開発ビルドでは最下部に配置
- 内容: Bridge 診断、フォント比較、コンポーネントプレビュー

## Accessibility

- グループ見出しに `accessibilityRole="header"`
- トグルに `accessibilityRole="switch"` + `accessibilityState={{ checked }}`
- 現在値を `accessibilityValue` で読み上げる
- 破壊的操作は `Dialog` で明示
- 行 50pt 以上

## Acceptance criteria

1. 設定が意味的なグループに整理されている
2. **開発者向け項目が本番ビルドに表示されない**
3. 破壊的操作に `Dialog` の確認がある
4. ローカル処理とクラウド処理の違いがユーザーの言葉で説明される
5. トグルが即座に反映・保存される
6. 現在値が各行に表示される
7. 行 50pt 以上
