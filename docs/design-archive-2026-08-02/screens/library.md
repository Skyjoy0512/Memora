# ライブラリ（旧案・新規実装しない）

> 2026-08-02の情報設計更新により、ファイル一覧とプロジェクト表示はホームへ統合した。本書は履歴資料として保持する。

ルート: `app/(tabs)/library.tsx`
種別: Bottom Tab

## Purpose

**過去の会議を探す。** 全件一覧と検索・絞り込みを提供する唯一の場所。

監査 C-2（会議一覧が独立した居場所を持たない）、M-3（検索が独立していない）の解決。

## User goal

「あの案件の先週の会議」に辿り着きたい。

## Information hierarchy

1. **検索欄**（常設）
2. 絞り込み（プロジェクト / 状態）
3. 会議一覧（日付降順、日付区切りあり）

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| 検索 | `SearchField`（`.Group/.SearchIcon/.Input/.ClearButton`） | — |

| 日付区切り | `Separator` + `Text` | `DateSeparator` |
| 会議カード | `Card` | `MeetingCard` |
| 状態 | `Chip` | `StatusChip` |
| 並び替え | `Menu` | — |
| 空状態 | `Card` + `Button` | `EmptyState` |
| 読み込み | `SkeletonGroup` | — |
| リスト | — | FlashList |

## Interactions

| 操作 | 結果 |
|---|---|
| 会議をタップ | 会議詳細へ |
| 会議を長押し | `Menu`: 書き出し / プロジェクト変更 / 削除 |
| 検索入力 | インクリメンタルに絞り込み |
| プロジェクトタグ | 絞り込み |
| プルダウン | 再読み込み |
| スクロール末尾 | 追加読み込み |

## States

| 状態 | 表示 |
|---|---|
| **空**（会議0件） | 「まだ会議がありません」+ 録音 CTA |
| **読み込み中** | `SkeletonGroup` |
| **通常** | 一覧 |
| **検索結果なし** | 「該当する会議がありません」+ 条件変更の提案 |
| **絞り込み中** | 適用中のタグを強調。解除導線を明示 |
| **オフライン** | ローカルの会議は表示。同期状態を明示 |

## Accessibility

- 日付区切りに `accessibilityRole="header"`
- 会議カードの読み上げを1つの意味単位にまとめる
- 絞り込みタグの選択状態を `accessibilityState={{ selected }}`
- 検索結果件数を読み上げる
- リスト行 50pt 以上

## Acceptance criteria

1. 会議の**全件**が日付降順で表示される
2. 検索が常設され、インクリメンタルに動作する
3. プロジェクトで絞り込める
4. 日付区切りが表示される
5. 会議が0件のとき録音 CTA が表示される
6. 長押しで補助操作が出る
7. FlashList でスクロール性能が保たれる
8. 絞り込み中はその状態が明示され、解除できる
