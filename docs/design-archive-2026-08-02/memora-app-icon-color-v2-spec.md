# Memora App Icon — Color v2

The icon is built on a 1024 × 1024 canvas using a golden-ratio-derived geometry system.

## Geometry

- Capsule width: `112`
- Capsule radius: `56`
- Horizontal gap: `69` (`112 ÷ φ ≈ 69.22`)
- Short capsule height: `293` (`112 × φ² ≈ 293.22`)
- Long capsule height: `474` (`112 × φ³ ≈ 474.41`)
- Symbol bounds: `x 184–839`, `y 188–836`
- Artwork background: `#FBFBF9`

## Color

Each capsule begins at the same neutral gray, creating one family, and resolves into a muted functional color.

- Shared gradient origin: `#AAACAD`
- Blue endpoint: `#788FAE`
- Teal endpoint: `#6C9FA1`
- Sage endpoint: `#798973`
- Violet endpoint: `#897A99`

The source SVG is the master. Export raster versions from it to avoid geometry drift.
