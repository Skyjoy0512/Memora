# ホーム

ルート: `app/(tabs)/index.tsx`
種別: Bottom Tab

## Purpose

**今の状況を把握する。** 一覧を提供する画面ではない。

「処理が終わったか」「やり残しはあるか」「直近に何を録ったか」の3点に答える。全件一覧はライブラリ、全タスクはタスクタブへ委ねる。

## User goal

アプリを開いて数秒で「いま自分が気にすべきこと」が分かる。

## Information hierarchy

上から順に:

1. **挨拶 + 日付**（軽い。省略可能な情報）
2. **処理中**（あれば最上位。無ければ非表示）
3. **最近の会議**（最大3件。全件はライブラリへ）
4. **未完了のタスク**（件数 + 上位3件。全件はタスクタブへ）

**セクションは「あるときだけ表示する」。** 空のセクション見出しを並べない。

初回・データなしの場合は空状態のみを表示する。

- 下部固定領域: タブバー + グローバルバー（あれば）
- **スクロール余白は「タブバー高さ + グローバルバー高さ + safe area」の合算で確保する。** 固定値を使わない（監査 H-5 の再発防止）

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| セクション見出し | `Text` | — |
| 「すべて見る」 | `LinkButton` | — |
| 処理中カード | `Card`（`.Header/.Title/.Body`） | `ProgressBar` |
| 会議カード | `Card` | `MeetingCard`（ラップ） |
| 状態表示 | `Chip` | `StatusChip`（ラップ） |
| タスク行 | `ListGroup`（`.Item/.ItemPrefix/.ItemTitle/.ItemDescription`）+ `Checkbox` | `TaskItem`（ラップ） |
| 空状態 | `Card`（`.Title/.Description/.Footer`）+ `Button` | `EmptyState`（ラップ） |
| 読み込み | `SkeletonGroup` | — |
| オフライン | `Alert` | — |

**`ListGroup` はタスク行に使う**（行区切りが意味を持つ）。セクション見出しには使わない。

## Interactions

| 操作 | 結果 |
|---|---|
| 会議カードをタップ | 会議詳細へ（Stack push） |
| 処理中カードをタップ | 会議詳細の該当タブへ |
| 「すべて見る」 | ライブラリタブへ切替 |
| タスクのチェック | その場で完了。`Toast` で取り消し可能に |
| タスク本文をタップ | タスク詳細へ |
| タスクの出典会議をタップ | 会議詳細へ |
| 検索アイコン | 検索モーダル |
| プルダウン | 再読み込み |

長押し・スワイプはホームでは使わない（発見性が低く、ホームは把握が目的のため）。

## States

| 状態 | 表示 |
|---|---|
| **初回・データなし** | 空状態のみ。「最初の会議を録音する」CTA を中央に |
| **読み込み中** | `SkeletonGroup`。実際のカード形状と一致させる |
| **通常** | 上記の情報階層 |
| **処理中あり** | 「処理中」セクションを最上位に表示 |
| **処理失敗あり** | 失敗した会議を「処理中」セクション内に `state-error` で表示。再試行ボタンを持つ |
| **オフライン** | 上部に `Alert`。ローカル処理は継続可能である旨を明示 |
| **録音中** | グローバル録音バーを表示。ホームの内容は通常どおり |

## Accessibility

- セクション見出しに `accessibilityRole="header"`
- 会議カードの読み上げ: 「{タイトル}、{日時}、{長さ}、{状態}」を1つのラベルにまとめる。要素を分割して読ませない
- 処理中の進捗は `accessibilityValue={{ now, min: 0, max: 100 }}`
- タスクのチェックは `accessibilityRole="checkbox"` + `accessibilityState={{ checked }}`
- 全タップ領域 44pt 以上、リスト行 50pt
- Dynamic Type でカードが破綻しないこと
- VoiceOver 読み上げ順: 挨拶 → 処理中 → 最近 → タスク → タブバー

## Acceptance criteria

1. 処理中の会議が0件のとき「処理中」セクションが**表示されない**
2. 最近の会議は**最大3件**。4件目以降は表示しない
3. 未完了タスクは件数を表示し、本文は**最大3件**
4. 「すべて見る」からライブラリ／タスクタブへ遷移できる
5. データが1件も無いとき、空状態と録音 CTA のみが表示される
6. スケルトンの形状が実際の会議カードと一致する
7. 処理失敗の会議に**再試行導線がある**
8. スクロール末尾のコンテンツがタブバーやグローバルバーに隠れない
9. VoiceOver で会議カードが1つの意味単位として読み上げられる
10. Dynamic Type を最大にしてもレイアウトが破綻しない
