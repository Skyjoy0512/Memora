# タスク

ルート: `app/(tabs)/tasks.tsx`
種別: Bottom Tab

## Purpose

**全会議から抽出されたやることを消化する。** 特定会議のタスクは会議詳細に表示するため、ここは横断ビュー。

## User goal

今日やるべきことを片付ける。それがどの会議から出たのか確認したい。

## Information hierarchy

1. 未完了（既定表示。期限順）
2. 完了済み（折りたたみ）

各タスク:
```
□ 見積もりを送る
  週次ミーティング より · 明日まで
```

**出典会議を必ず表示する**（監査 C-3）。

## Layout

```
┌─────────────────────────────────┐

│                                 │

│                                 │

│                                 │

```

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| 未完了/完了 切替 | `Tabs` | — |
| タスク行 | `ListGroup`（`.Item/.ItemPrefix/.ItemTitle/.ItemDescription`）+ `Checkbox` | `TaskItem` |
| 期限グループ見出し | `Text` | `SectionHeader` |
| 期限 | `Chip` | — |
| 追加 | `BottomSheet` + `TextField` | — |
| 空状態 | `Card` | `EmptyState` |
| 完了通知 | `Toast` | — |

## Interactions

| 操作 | 結果 |
|---|---|
| チェック | 完了。`Toast` で取り消し可能 |
| タスク本文をタップ | タスク詳細へ |
| **出典会議をタップ** | 会議詳細へ |
| 長押し | `Menu`: 期限設定 / 編集 / 削除 |
| 手動追加 | `BottomSheet` で入力 |

## States

| 状態 | 表示 |
|---|---|
| **空** | 「やることはありません」 |
| **未完了なし・完了あり** | 「すべて完了しています」 |
| **読み込み中** | `SkeletonGroup` |
| **通常** | 期限グループごとの一覧 |
| **期限超過** | `state-warning` で強調 |

## Accessibility

- チェックに `accessibilityRole="checkbox"` + `accessibilityState={{ checked }}`
- 読み上げ: 「{内容}、{出典会議}より、{期限}」
- 期限超過を色だけで表さない（テキストを伴う）
- 行 50pt 以上

## Copy

| 要素 | テキスト |
|---|---|
| タブ | 「未完了」「完了」 |
| 期限グループ | 「今日まで」「明日まで」「今週」「期限なし」「期限切れ」 |
| 出典 | 「{会議名} より」 |
| 空状態 | 「やることはありません」 |
| 全完了 | 「すべて完了しています」 |
| 完了通知 | 「完了しました」+「取り消す」 |

## Acceptance criteria

1. **各タスクに出典会議が表示される**
2. 出典会議のタップで会議詳細へ遷移できる
3. 未完了が既定表示
4. 期限順にグループ化される
5. 完了時に取り消しできる `Toast` が出る
6. 期限超過が色以外でも分かる
7. 行 50pt 以上
