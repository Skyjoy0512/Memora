# 要約

配置: 会議詳細（`meeting/[id]`）内のタブ。既定で選択される。

## Purpose

**会議の内容を短時間で把握する。** 全文を読まずに要点・決定事項・やることを掴む。

## User goal

30分の会議を1分で理解したい。

## Information hierarchy

1. **要点**（3〜5行。最重要）
2. **決定事項**
3. **やること**（タスクへの入口）
4. **キーフレーズ**
5. **メモ**（ユーザーが書き足す領域。旧メモタブを統合）

セクションは内容があるものだけ表示する。

## Layout

```
┌─────────────────────────────────┐
│ ┌─要約─┬─文字起こし─┬─タスク─┐ │
│ └══════┴───────────┴────────┘ │
│                                 │
│ 要点                             │
│ ・来期予算の方針を確認した        │
│ ・広告費を20%削減する             │
│                                 │
│ 決定事項                         │
│ ・A案で進める                    │
│                                 │
│ やること                    3件  │
│ □ 見積もりを送る（田中）          │
│                                 │
│ キーフレーズ                     │
│ [予算] [広告費] [A案]            │
│                                 │
│ メモ                             │
│ ┌───────────────────────────┐   │
│ │ 自由に書ける領域            │   │
│ └───────────────────────────┘   │
│                                 │
├─────────────────────────────────┤
│ ▶ 再生バー                       │
├─────────────────────────────────┤
│ [この会議について質問する]        │
└─────────────────────────────────┘
```

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| セクション見出し | `Text` | `SectionHeader` |
| 要点・決定事項 | `Text`, `ListGroup` | `SummarySection` |
| やること | `ListGroup` + `Checkbox` | `TaskItem` |
| キーフレーズ | `TagGroup` / `Chip` | — |
| メモ | `TextArea` | — |
| 折りたたみ | `Accordion` | — |
| 未生成 | `Card` + `Button` | `EmptyState` |
| 失敗 | `Alert` + `Button` | — |
| 生成設定 | `BottomSheet` + `RadioGroup` | — |

## Interactions

| 操作 | 結果 |
|---|---|
| やることのチェック | その場で完了 |
| やることをタップ | タスク詳細へ |
| キーフレーズをタップ | そのフレーズで文字起こし内を検索 |
| メモを編集 | 自動保存。保存状態を表示 |
| 再生成 | `BottomSheet` でテンプレート・モデルを選び再生成 |
| 要点をタップ | 該当箇所の文字起こしへジャンプ（可能な場合） |

## States

| 状態 | 表示 |
|---|---|
| **未生成** | 「要約を作る」CTA。文字起こしが未完了なら理由を表示 |
| **生成中** | `Spinner` +「要約を作っています」 |
| **完了** | 上記の情報階層 |
| **失敗** | `Alert` + 理由 + 再試行 |
| **文字起こし未完了** | 「文字起こしが終わると要約を作れます」 |
| **オフライン**（クラウド処理時） | 「オンラインになったら作成します」 |
| **上限到達** | 「今月の要約の上限に達しました」+ プラン案内 |
| **メモ保存中 / 未保存** | 保存状態を控えめに表示 |

## Accessibility

- セクション見出しに `accessibilityRole="header"`
- キーフレーズの `Chip` に「{語句}で検索」の `accessibilityHint`
- メモの `TextArea` に `accessibilityLabel="この会議のメモ"`
- やることのチェックに `accessibilityRole="checkbox"`
- 保存状態は `accessibilityLiveRegion="polite"`
- 全タップ領域 44pt 以上

## Acceptance criteria

1. 要約タブが**既定で選択される**
2. 内容が無いセクションは表示されない
3. **メモが要約タブ内のセクションとして統合されている**（メモタブ廃止）
4. やることからタスク詳細へ遷移できる
5. キーフレーズから文字起こし内検索ができる
6. 文字起こし未完了時、理由が説明される
7. 失敗時に再試行できる
8. メモの保存状態が分かる
9. 要約の再生成でテンプレート・モデルを選べる
10. VoiceOver でセクション構造が伝わる
