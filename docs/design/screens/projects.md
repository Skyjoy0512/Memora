# プロジェクト詳細

ルート: `app/project/[id].tsx`
種別: Stack（card）

## Purpose

**1つの案件に紐づく会議とタスクをまとめて見る。** Project 概念を UI 上で可視化する（監査 C-3）。

## User goal

この案件で何が話され、何が残っているかを把握する。

## Information hierarchy

1. プロジェクト名と概要
2. 会議数・タスク数
3. 会議一覧（このプロジェクトのみ）
4. 未完了タスク（このプロジェクトのみ）

## Layout

```
┌─────────────────────────────────┐
│ ← 週次定例              [⋯]     │
├─────────────────────────────────┤
│ 会議 12件 · 未完了タスク 3件      │
│                                 │
│ 会議                    すべて見る│
│ ┌───────────────────────────┐   │
│ │ 定例会議                   │   │
│ └───────────────────────────┘   │
│                                 │
│ 未完了のタスク                   │
│ □ 見積もりを送る                 │
│                                 │
└─────────────────────────────────┘
```

## Components

| 要素 | HeroUI Native | Custom |
|---|---|---|
| 概要 | `Card` | — |
| 統計 | `Text`, `Chip` | — |
| 会議一覧 | `Card` | `MeetingCard` |
| タスク | `ListGroup` + `Checkbox` | `TaskItem` |
| その他操作 | `Menu` / `BottomSheet` | — |
| 名称変更 | `Dialog` + `TextField` | — |
| 削除確認 | `Dialog` | — |
| 空状態 | `Card` | `EmptyState` |

## Interactions

| 操作 | 結果 |
|---|---|
| 会議をタップ | 会議詳細へ |
| すべて見る | ライブラリ（このプロジェクトで絞り込み済み） |
| ⋯ | 名称変更 / 削除 |
| 削除 | **`Dialog` で確認。** 会議は削除されないことを明示 |

## States

| 状態 | 表示 |
|---|---|
| **空** | 「このプロジェクトにはまだ会議がありません」 |
| **通常** | 会議・タスク一覧 |
| **読み込み中** | `SkeletonGroup` |

## Accessibility

- セクション見出しに `accessibilityRole="header"`
- 削除の `Dialog` で「会議は削除されない」ことを読み上げる

## Copy

| 要素 | テキスト |
|---|---|
| 統計 | 「会議 {n}件 · 未完了タスク {n}件」 |
| 空状態 | 「このプロジェクトにはまだ会議がありません」 |
| 削除確認 | 「このプロジェクトを削除しますか」 |
| 削除説明 | 「会議は削除されません。プロジェクトの分類のみ解除されます」 |

## Acceptance criteria

1. プロジェクトに属する会議とタスクが表示される
2. 「すべて見る」でライブラリの絞り込み状態へ遷移する
3. **削除時に会議が消えないことが明示される**
4. 空状態で次の行動が示される
