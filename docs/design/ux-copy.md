# UX ライティング

作成日: 2026-07-26
原則: **技術用語をユーザーに見せない。** 状態と次の行動が分かる言葉にする。

## 基本方針

1. **状態は「何が起きているか」を動詞で言う。** `processing` ではなく「文字起こしを作っています」
2. **失敗は理由と次の行動を必ず含む。** 「失敗しました」で終わらせない
3. **破壊的操作は結果を明示する。** 「削除しますか」ではなく「録音・文字起こし・要約がすべて削除されます」
4. **専門用語を避ける。** モデル / トークン / API / キャッシュ / セッション
5. **簡潔にする。** ボタンは4文字前後、説明は2行以内

## 録音

| 場面 | 文言 |
|---|---|
| 録音開始 | 「録音を開始」 |
| 録音中 | 「録音中」 |
| 一時停止 | 「一時停止」 |
| 一時停止中の状態 | 「一時停止中」 |
| 再開 | 「再開」 |
| 停止 | 「停止」 |
| 破棄 | 「録音を破棄」 |
| 破棄の確認 | 「録音を破棄しますか」／「録音した音声は削除され、元に戻せません」 |
| 破棄の実行 | 「破棄する」 |
| 破棄の取消 | 「録音を続ける」 |
| 保存中 | 「保存しています」 |
| 録音失敗 | 「録音が中断されました。ここまでの音声を保存できます」 |
| 部分保存 | 「ここまでを保存」 |

**「停止」と「破棄」を絶対に混同させない。** 停止＝保存される、破棄＝消える。

## 処理

| 場面 | 文言 |
|---|---|
| 保存中 | 「保存しています」 |
| モデル準備 | 「音声認識の準備をしています」 |
| モデル準備の補足 | 「初回のみ、少し時間がかかります」 |
| 文字起こし中 | 「文字起こしを作っています」 |
| 話者判別中 | 「話している人を分けています」 |
| 要約生成中 | 「要約を作っています」 |
| タスク抽出中 | 「やることを探しています」 |
| 残り時間 | 「あと{n}分ほどで終わります」 |
| 完了 | 「読めるようになりました」 |
| 順番待ち | 「順番を待っています」 |

**使わない語**: `queued` `transcribing` `summarizing` `processing` `pending` `キュー` `ジョブ`

## 失敗と回復

| 場面 | 文言 |
|---|---|
| 文字起こし失敗 | 「文字起こしができませんでした」 |
| 理由・音声が短い | 「音声が短すぎるようです」 |
| 理由・通信 | 「通信が不安定でした」 |
| 理由・不明 | 「うまくいきませんでした」 |
| 要約失敗 | 「要約を作れませんでした」 |
| 再試行 | 「もう一度試す」 |
| あとで | 「あとで」 |
| 部分失敗 | 「文字起こしはできています。要約だけ作り直せます」 |

**すべての失敗に再試行または代替手段を添える。**

## オフライン

| 場面 | 文言 |
|---|---|
| オフライン通知 | 「オフラインです」 |
| 録音は可能 | 「録音と文字起こしは続けられます」 |
| クラウド処理待ち | 「オンラインになったら続きを行います」 |
| 機能制限 | 「この操作にはインターネット接続が必要です」 |

## 権限

| 場面 | 文言 |
|---|---|
| 未取得 | 「録音するにはマイクの許可が必要です」 |
| 要求ボタン | 「マイクを許可」 |
| 拒否済み | 「設定アプリでマイクを許可してください」 |
| 設定へ | 「設定を開く」 |

**拒否済みでも必ず復帰手段を示す。**

## プランと上限

| 場面 | 文言 |
|---|---|
| 上限接近 | 「今月の残りは{n}回です」 |
| 上限到達 | 「今月の文字起こしの上限に達しました」 |
| 案内 | 「プランを変更すると続けられます」 |
| プランを見る | 「プランを見る」 |
| 無料プラン表示 | 「無料」 |

**上限到達を責めない言い方にする。**

## 処理方式

| 場面 | 文言 |
|---|---|
| ローカル | 「この端末で処理」 |
| ローカルの説明 | 「音声は外部に送信されません」 |
| クラウド | 「クラウドで処理」 |
| クラウドの説明 | 「より高い精度で処理されます」 |

**`ローカル` `オンデバイス` `API` を単独で使わない。**

## 保存

| 場面 | 文言 |
|---|---|
| 保存済み | 「保存しました」 |
| 保存中 | 「保存しています」 |
| 未保存 | 「保存されていません」 |
| 自動保存の説明 | 「入力すると自動で保存されます」 |

## 削除

| 場面 | 文言 |
|---|---|
| 会議削除の確認 | 「この会議を削除しますか」 |
| 会議削除の説明 | 「録音・文字起こし・要約がすべて削除されます。元に戻せません」 |
| プロジェクト削除の確認 | 「このプロジェクトを削除しますか」 |
| プロジェクト削除の説明 | 「会議は削除されません。プロジェクトの分類のみ解除されます」 |
| 実行 | 「削除する」 |
| 取消 | 「キャンセル」 |
| アカウント削除の説明 | 「すべての会議と録音が削除されます。元に戻せません」 |

**何が消えて何が残るかを必ず書く。**

## 空状態

| 場面 | 文言 |
|---|---|
| 会議なし（初回） | 「最初の会議を録音しましょう」／「録音すると、文字起こしと要約が自動で作られます」 |
| 会議なし（ライブラリ） | 「まだ会議がありません」／「録音すると、ここに会議が並びます」 |
| タスクなし | 「やることはありません」 |
| タスク全完了 | 「すべて完了しています」 |
| 検索結果なし | 「該当する会議がありません」 |
| 文字起こしなし | 「文字起こしはまだありません」 |
| 要約なし | 「要約はまだありません」 |
| 無音 | 「音声から発言を検出できませんでした」 |

## ボタン文言の統一

| 意味 | 文言 |
|---|---|
| 作成 | 「作る」（「生成」を使わない） |
| 再作成 | 「作り直す」 |
| 再試行 | 「もう一度試す」 |
| 開始 | 「始める」／「開始」 |
| 確定 | 「保存」 |
| 取消 | 「キャンセル」 |
| 閉じる | 「閉じる」 |
| すべて表示 | 「すべて見る」 |

**「生成」「実行」「送信」のような機械的な語を避ける。**
